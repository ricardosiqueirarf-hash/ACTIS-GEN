## Decisões técnicas

- O endpoint público `/v1/models` não é fonte suficiente: expunha apenas 8 modelos Kilo enquanto a própria UI do 9Router mostrava 21 modelos free adicionais.
- O ACTIS usa a autenticação local CLI do 9Router (`x-9r-cli-token`) calculada localmente a partir dos arquivos do próprio 9Router; token/secret nunca são retornados à UI.
- O probe usa `/api/models/test`, permitindo enxergar o erro upstream real (ex.: 429/402) mesmo quando o endpoint OpenAI-compatible reduz o erro a 503.
- Resultados de probe ficam persistidos no SQLite do ACTIS e sobrevivem a restart.
- Modelos free são priorizados dentro de cada rota; rotas são alternadas em round-robin.
- Modelos com quota esgotada recebem cooldown muito maior; rate limit com `reset after` usa esse tempo como base.
